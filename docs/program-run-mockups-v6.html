Tropos · Programme + Run · v6 edge states

Doubles · race elapsed · history nav · completion celebration

Four edge cases not yet covered in v3-v5: visual indicator for doubles days (lift + run same day), race-prep elapsed states (race complete vs no-show), history navigation (viewing past weeks), and post-run completion celebration. Each handled inside the existing chassis — no new pages, no new components, just states.

Updated build summary

Total: ~6 days (up from 5 in v5 — v6 covers all the edge states)

v6 additions:

  • Doubles dot indicator · 12px coral/purple dot positioned on day-stepper circles · pure visual · ~0.25 days
  • Race-prep elapsed states · two variants (race complete with celebration / race passed with muted) · ~0.5 days
  • History navigation · WeekPhaseRow chevrons activate · session card morphs to result view · "Back to this week" banner · week summary block · ~0.75 days
  • Completion celebration · win banner (auto-dismisses 48h) · stats grid flips to actual-vs-target · PR badge for personal records · "Up next" preview · ~0.5 days

All edge states reuse existing components. The doubles dot, win banner, history banner, and "Up next" card are small additions to the existing Run view shell — not new pages.

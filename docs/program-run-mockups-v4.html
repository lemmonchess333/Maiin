Tropos · Programme + Run · v4 mockups

Iteration 4 · full feature coverage + visual polish

Extends v3 with the missing screens: full 12-week race plan modal, plan settings sheet, no-plan setup flow, "+ Add another run today" sheet, skipped session handling, and a dense 5-run-week check. Plus tighter visuals — leading run-type icon on the session card, soft ghost button (not text-link) for "Just go for a run", and a small "View full plan" affordance baked into the race strip.

Changes from v3

  • Session card has a leading run-type icon (44px coral square with the type glyph). Same pattern as iOS notification icons.
  • "Just go for a run" upgraded from text-link to a soft coral ghost button — visible at thumb level without competing with the primary Start.
  • Race strip gains a "View full plan ›" link inside the card (top-right of the strip).
  • New: full 12-week plan modal with mileage bar chart + week-by-week list.
  • New: plan settings bottom-sheet — distance / date / runs-per-week picker.
  • New: no-plan setup flow — what footprint shows when user is freeform but wants to upgrade.
  • New: "+ Add another run today" sheet — quick picker for an extra session.
  • New: missed session state — coral circle with warning dot + "Catch up tomorrow?" affordance.
  • New: 5-run-week density check — does the stepper still feel right?

"Won't affect your plan"Critical subtitle. The user has completed today's planned tempo. This extra run is ad-hoc — it doesn't satisfy tomorrow's planned long run.
Easy run firstEasy run is the most common reason people add a second session (recovery, dog walk run). Surface it.

Edge caseIf user adds 2+ extra runs in one day, the doubles indicator on tomorrow's stepper shouldn't double-count. Track ad-hoc runs separately from planned.

| D18 | P2       | Run HUD (`RunBottomSheet`)  | UI labels below the documented text floor                 | **Open — deliberately not fixed blind**     | 27 hardcoded sub-11px `fontSize` values across the app, concentrated in `RunBottomSheet` at **8 and 9px**. DESIGN_GUIDE puts the floor at `text-micro` 12px, and `SectionLabel`'s own docstring calls 11px "the app-wide minimum text size (accessibility floor)" — so these are roughly half the sanctioned minimum, on the surface people read while moving, often outdoors. Genuinely worth fixing. NOT fixed here because **the live run HUD is captured nowhere**: only `run-detail` (the history page) has frames, and raising ~15 labels in a dense full-screen HUD without being able to see the result is how two regressions reached main on 2026-08-21. | D19 | P2       | Palette (`theme.ts`)        | Warning, danger and success are aliases of domain colours | **Open — palette decision, not a refactor** | `THEME.warning` is `#D9884E`, byte-identical to `THEME.semantic.nutrition`. `THEME.danger` is `#D4637A`, identical to `semantic.vitals` AND `semantic.negative`. `THEME.success` is `#4DB872`, identical to `semantic.positive`. All three live in a block `theme.ts` labels "Legacy semantic (kept for compatibility)". Consequence: CLAUDE.md's warning-register rule — "warnings use `THEME.warning`; orange is the FOOD identity, never a warning colour" — cannot do what it says. Moving a callout onto the warning token is a pixel-for-pixel no-op, and every consumer of `THEME.warning` renders its warning in the food colour (the deload banner is the visible case: an amber "Consider a deload week" on a lifting surface). Not fixed here because DESIGN_GUIDE closes the palette — "no new colours unless added as tokens" — so picking a warning hue is a design decision, not a cleanup. If taken: give `warning` its own token, keep the alias for one release, and note that `danger`/`vitals` colliding also means a destructive action and a heart-rate readout are the same coral. The CLAUDE.md rule has been corrected to state the current reality rather than imply a separation that does not exist. |

## Scope limits

Static source inspection does not establish all six-frame playback transitions, especially the top/return holds, nor compressed delivery quality. Three-pose sequences deliberately reuse endpoint and return frames. Production release must remain false until outstanding technique/equipment findings and actual mobile player review are resolved.

# Form Motion V2 — Gate 0 contact sheets

Five-frame acceptance samples (t = 0/.25/.5/.75/1) for **every**
registered body demo, rendered via the review path (production-gated
demos included). Generated by `npx tsx scripts/preview-rig.ts
docs/visual-audit/form-motion-v2`; `manifest.json` records the exact
(t, effort) per frame so a review is tied to what it approved.

Interactive companion: `/dev/form-motion-lab` (dev builds only).

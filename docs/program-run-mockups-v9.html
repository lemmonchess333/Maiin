Tropos · Spec v7 visual companion · v9 (style-aligned)

Every affected page, rendered with real Tropos primitives

Rebuild of v8 after the style audit. Every visual now matches the actual app: Lucide icons throughout (zero emojis), soft var(--ds-shadow-card) shadows (no hard borders), OptionCard pattern for all selections, vaul BottomSheet for modals, THEME.* tokens for all colours, real toggle dimensions. Mockups now match what the build will actually look like.

What changed from v8 → v9

  • Zero emojis. All icons inline as Lucide SVG. Dumbbell · Footprints · Trophy · Target · Zap · Mountain · PersonStanding · Flame · RefreshCw · AlertTriangle · Info · Check · ChevronRight · X · MoreHorizontal · Plus · LayoutGrid · Sparkles.
  • No hard borders on cards. Everything uses var(--ds-shadow-card) (soft layered shadow). Single 1px border on OptionCard only (matches existing pattern).
  • Real OptionCard pattern. Selections use the actual onboarding component: bg-card border unselected, THEME.teal}18 + THEME.teal}50 selected, icon-left + label/description + animated Check right.
  • Configure Plan = BottomSheet, not full-screen modal. Sheet with handle, padded body, footer with Cancel/Confirm. max-h-[95vh] for the multi-step wizard.
  • Win banner = card with Lucide Trophy. No gradient. bg-card + soft shadow + gold-tinted icon container.
  • Notice cards = card, not left-border accent. The doubles banner, race-elapsed banner, and reconciliation prompt all use the same notice-card pattern: bg-card + icon-left + text.
  • Segmented control = WorkoutSession scrolling pills. Filled pill for active state on the brand colour (or running for Run tab).
  • Toggle dimensions match. w-10 h-6 with w-4 h-4 slider — matches the existing hand-rolled switch in ProgramSettingsPanel.
  • Circular DayStepper preserved. Matches DayStepper.tsx exactly: 40px default, 48px today with glow.
  • Race strip preserved. Soft tinted card with radial accent, no hard border. Same as v6/v7/v8.

Recap · component primitive map

Net new components for v7 spec:

  • SegmentedControl.tsx — Programme tabs (WorkoutSession pill pattern)
  • ScheduleRow.tsx — Week tab list rows
  • WinBanner.tsx — completion celebration (card with Lucide Trophy)
  • NoticeCard.tsx — info/warning/success notices (replaces all left-border banners)
  • RaceStrip.tsx — race-prep flagship surface
  • ConfigurePlanSheet.tsx — wraps BottomSheet for the 6-step wizard
  • MismatchReconciliationSheet.tsx — wraps BottomSheet for save-time reconciliation

Reused components (zero new code):

  • OptionCard.tsx — every selection in onboarding, Configure Plan, reconciliation
  • BottomSheet.tsx — every modal/sheet
  • Button.tsx — every CTA (5 existing variants)
  • Coachmark.tsx — first-use tab tooltip
  • DayStepper.tsx — Lift tab (unchanged) + optional coral dot for doubles
  • WeekStrip.tsx — extended to read weekSchedule
  • DayPeekCard.tsx — extended with planned/missed/completed variants
  • All Lucide icons — Dumbbell, Footprints, Trophy, Target, Zap, Mountain, AlertTriangle, etc.

7 new components. 8+ reused. Everything else (colours, shadows, typography, spacing) inherits from src/lib/theme.ts + src/styles/tokens.css.

Three-flow architecture · variable race-prep durations

Clarifies the relationship between the three modes the user can be in: Structured (weekly cadence, no race), Race Prep (variable duration — 4 weeks for a quick 5K, 24 weeks for a marathon), and Ad-hoc (lands at the existing /run setup, untouched). The Programme tab becomes the single hub for all three.

Visual switching thresholds

  • 1-7 weeks: Single progress bar (no segments, no dots). Plan is too short for periodisation to feel meaningful.
  • 8-16 weeks: One dot per week. Visible weekly progression. Sweet spot.
  • 17+ weeks: Three-segment phase bar (Base/Build/Taper) with a current-week marker. Avoids dot crowding.

"Just go for a run" — access points across all states

The affordance isn't a single button. It appears in every Run-view context where it makes sense — varies in framing to match the context but always lands at /run setup with no preset target.

Context Where it appears Copy Visual weight
Today has a planned run Session card · below "Start [planned]" "Just go for a run" Ghost button · coral outline
Today is a rest day Rest pill · primary action "Just go for a run anyway" Solid secondary · grey fill
Today's run completed Completed card · footer text-link "+ Add another run today" Coral text · opens picker sheet
Missed session Missed card · secondary "Skip this week's tempo" Warning ghost · explicit dismissal
No plan yet (empty state) Below plan setup options · bottom "Or just go for a run" Ghost button · centred
Plan settings sheet Mode picker · "Freeform" option "Freeform — run when you like" Radio option (changes mode permanently)
Mode A user (no plan) Footprint icon itself (direct nav to /run) Default behaviour

Why it's never a single button

The Outsider council member said "I'd never look top-right for an action." Putting the freeform shortcut anywhere fixed would either over-burden the chrome (button in every header) or hide it (single spot users miss). Instead it lives contextually — wherever the user's thumb is when they're considering doing something different from the plan. Same destination (/run), seven different framings.

The switcher pattern

The footprint icon top-right of Programme is the single entry point. Tap it on Lift view → page content switches to Run view. The icon itself swaps from a coral footprint to a purple dumbbell so the next tap brings lifts back. One affordance, two states, no extra chrome.

On Lift view the top-right icon is a coral footprint. Tap → Run view.
→
On Run view the icon swaps to a purple dumbbell. Tap → back to Lift view.
→

For users without a structured run plan the footprint never becomes a switcher — it goes straight to /run as it does today. The view-switcher state is only active when runDays?.length > 0.

v1.1 — what the "Just go for a run" link could grow into

The Expansionist council member flagged this surface as the most undervalued real estate in the app. Today it ships as a single text link. Over the next 6 months it can grow into a smart "Run now" sheet without changing the entry point.

Roadmap: "Run now" intelligent sheet

Tapping "Just go for a run" today opens /run with freeform setup. Tomorrow it could open a bottom sheet with context-aware suggestions:

  • v1.0 (now): Tap → /run freeform. Single link. Ship.
  • v1.1 (weather-aware): Sheet shows "Good window: 18°C, low wind, next 90 min." Data already in weather.ts.
  • v1.2 (recovery-aware): "Your legs logged a hard session yesterday — 25 min Z2 suggested." performanceEngine.ts knows.
  • v1.3 (social): "Sarah is running in 20 min nearby." Foothold for spontaneous group runs Strava hasn't nailed.
  • v1.4 (make-up): "You missed Tuesday's tempo — slot it now?" Reconnects ad-hoc back to the plan.

No changes needed to:

  • Lift Programme rendering — same code path when view === 'lift'
  • useProgram hook — already populates runDays + runPlan

  • Phase B1 metadata wiring — "Just go for a run" navigates to /run with no prefill, just like today's freeform setup

  • Bottom nav — Programme tab stays single

Regression surface: tiny. The Lift view is gated and renders identically. The Run view is brand new and isolated. The switcher is a single state flag.

Tropos · Programme + Run · v2 mockups

Two approaches mocked in real Tropos visual language

Rebuilt to match the existing design system: circular DayStepper, soft tinted backgrounds, no hard borders, iOS-grouped feel, Plus Jakarta Sans system font. Mocks both approaches: your idea (Run Programme page accessed via the footprint icon) and the council's (unified Programme with both modalities), plus a recommended Hybrid A.

Fixes from the v1 mockup feedback

The previous mockup used rectangular calendar cells with hard borders — a generic AI-grid aesthetic that ignored everything Tropos already does well. This version:

  • Circular DayStepper (40px / 48px today with coloured glow) — matches DayStepper.tsx
  • Soft tinted backgrounds, zero hard borders
  • WeekPhaseRow with prev/next arrows for navigation
  • Tiny labels under circles, not above-the-fold chrome
  • Race strip as a soft tinted hero card with a subtle radial accent — not a bordered box
  • Coral footprint icon already exists top-right of Programme with Coachmark — preserved as entry point
  • System font stack baked in (no Google Fonts dependency) — fully offline

Recommendation

Ship Hybrid A. It captures the wins of your idea (parallel chassis, clean focus, race-prep flagship surface, future-proofs cycling/swimming) while solving the council's strongest concern (doubles-day awareness) with a single small UI element (the bridge chip).

The build, roughly:

  • New src/pages/RunProgramme.tsx — clones Program.tsx chassis, reads runDays instead of workouts, coral instead of purple (~1.5 days)
  • New route: /program/runs behind the existing RunningNavIcon (already in place)
  • RunSessionCard.tsx — coral variant of the lift session card (~0.5 days)
  • BridgeChip.tsx — conditional, renders on Program.tsx when today has a planned run (~0.5 days)
  • No data model changes. ProgramState.runDays + runPlan already populated by useProgram

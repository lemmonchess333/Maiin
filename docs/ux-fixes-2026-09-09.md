# UX fixes — 9 September 2026

Implementation record for the approved UX fixes. Release progress and checks are tracked in [server support PR #2216](https://github.com/lemmonchess333/Maiin/pull/2216) and [UI PR #2217](https://github.com/lemmonchess333/Maiin/pull/2217).

| Improvement               | Result                                                                                                                                                                                                                                        |
| ------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Correct completed sets    | Every completed row has Edit. Weight and reps can be corrected after Undo expires, and a finished workout can be reopened before its first save. Invalid input stays in the editor; cancelling preserves the original set.                    |
| Preserve workout results  | Corrections rebuild personal records from history and the final sets. A correction to the progression-driving set replaces that session's result against its original prescription, including offline, instead of applying progression twice. |
| Accurate Home status      | Completed, Skipped and Needs review have distinct labels. A saved-run claim counts as completion even when the old stored status is still Planned.                                                                                            |
| Open saved sessions       | Run Done returns to the Run tab. Completed programme days open their exact saved workout or run when its identity is known. Older ambiguous records keep a History fallback.                                                                  |
| Faster Form guidance      | Form opens before workout history has loaded. Statistics appear under Progress, leaving guidance first on Form.                                                                                                                               |
| Clearer calendar          | Both sports use checks for completed sessions and dashes for skipped sessions. Today is outlined; the selected day is filled. Two-letter weekdays reduce ambiguity.                                                                           |
| Visible manual food entry | Enter manually is always available beneath the food composer.                                                                                                                                                                                 |
| Clearer session rows      | Saved-session rows have larger text, a 44px minimum tap target and a trailing chevron.                                                                                                                                                        |
